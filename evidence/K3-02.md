- SHA run: `f7409bdd3515209be572f48b1b3435fcda6bb462`
- Runner: `ubuntu-latest`, фактическое имя runner для test: `GitHub Actions 1000000034`
- Job: `test`

Шаг `checkout` скачивает код именно той ревизии, которую проверяет этот run. Шаг `setup-python` устанавливает Python 3.13. После него команда `python --version` проверяет, что Python доступен на runner. В этом же run были отдельный шаг с тестами и job сборки.

Одного зелёного шага `python --version` недостаточно: он подтверждает только наличие Python, но не показывает, что приложение правильно сохраняет заявки. Это проверяется отдельным запуском unittest.
